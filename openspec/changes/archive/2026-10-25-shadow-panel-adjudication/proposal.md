# Proposal: a model panel adjudicates the IMPLEMENT and REVIEW shadow corpora

> **Not shipped.** Archived 2026-10-25 without applying its spec: both legs were closed INCONCLUSIVE before registration. See design.md, "Outcome 2026-10-25".

## Why

Both shadow legs of the push gate record would-block events so a pre-registered
rule can decide whether the leg may start denying. Neither has ever been
adjudicated. Measured 2026-10-23:

- IMPLEMENT (`predicate_version 5`): 58 would-block episodes, 0 adjudicated.
  Transcripts older than 30 days were already deleted (18 records lost).
- REVIEW (`predicate_version 2`): 142 episodes, 0 adjudicated. The first REVIEW
  window was CLOSED as a null result on 2026-09-23 because nobody labelled
  anything; its closing amendment says a successor must name the adjudicator and
  the cadence, and ship the reader with the writer.

Labels today count only when human-claimed. The owner has decided (2026-10-23)
to replace the human adjudicator with a panel of models: two fresh Claude
instances plus Codex, each labelling the same evidence blind to the others.

The owner's stated ground was that a panel is more objective than one person.
That is not the validation argument this change relies on. The panel is an
amended measurement procedure, and planted episodes with known answers check
it. They can detect the failures they represent and no others.

## What Changes

- **Amendments to both pre-registrations, committed before any label exists.**
  The IMPLEMENT window gets a new adjudicator. A new REVIEW window is
  registered. Floors, bands, episode definition and verdict definitions are
  unchanged. One stricter safeguard is added: DENY-eligibility also needs
  `unknown` episodes to be at most 10% of the cohort. The worst-case rate stays
  reported only, as registered. `n` is named once for both legs (`true_catch` +
  `false_block`), and "warned, pushed anyway" is read as a true catch.
- **A frozen cohort and order.** The cohort is the reader's rate population at
  registration, less the 8 episodes already lost by age, which are listed. Its
  order is drawn from a seed fixed at registration, and there is one decision
  analysis, when the cohort is complete.
- **A deterministic evidence-packet extractor** (`scripts/shadow-panel-packet.py`).
  It writes one packet per episode, with a coverage manifest stating what it
  could not find.
- **A panel runner** (`scripts/shadow-panel.sh`). Claude judges run as `claude -p`
  with no tools, in an isolated HOME, with the model pinned. Codex runs through
  `scripts/consult-dispatch.sh`. Raw responses, digests and configuration are
  stored per item.
- **Deterministic aggregation.** A label stands only when all three judges agree
  on `true_catch` or `false_block`. Anything else is `unknown`.
- **80 planted control episodes**, 40 per leg, generated by running the real gate
  in throwaway repositories and judged first as a qualifying round. A leg whose
  panel fails its controls does not start its real cohort.
- **The readers count `claimant: "panel"` labels.** `scripts/shadow-adjudicate.sh`
  and `scripts/review-shadow-adjudicate.sh` accept them, under the amended
  windows only, and report the control status beside the band.
- **Transcript preservation** into a private local archive. It already holds 28
  transcripts (2026-10-23), and `cleanupPeriodDays` is now 180, set by the owner.
- **A weekly cadence** with a named accountable operator (the owner).

## Not changing

- The gate. Every script here is diagnostic-only, excluded from
  `_GATE_ENFORCE_LIBS`, and never read by `hooks/openspec-guard.sh`.
- Any floor, band, `false_block`/`true_catch` definition, or episode rule.
- Whether a leg starts denying. A DENY band licenses a separate owner decision
  and does not flip anything.
