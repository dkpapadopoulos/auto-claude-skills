2. **Portfolio: ranked objections**

1. **G5, automatic fixes versus ASK:** actively harmful scope expansion for a reviewer. Requiring permission whenever a regression test is needed penalizes precisely the fixes with useful verification.
2. **T2, premature-action scoring:** rewards ritual ordering. Reading relevant code before invoking a skill can be correct; treating it as failure confuses compliance with engineering quality.
3. **T3, blanket abstention on off-mission prompts:** wrong target. A marketing or legal task can legitimately need authorial judgment, discovery, or consultation. Label intended skills per case.
4. **T4b/E4 and G8:** ratchets, mandatory sibling descriptions, and generated eval stubs can become expensive bookkeeping. A stub’s existence does not make the done-gate behavioral.
5. **T1’s acceptance rule:** requiring removal of a hint to reduce uptake assumes the hint works. Equal arms can mean a correct instrument measuring redundancy; demanding a gap invites harness tuning until the desired result appears.

**Best value/risk: F1’s parser correction**, separately from reprioritization. It repairs deterministic data corruption with a small regression surface.

“Instruments before interventions” is right for new per-prompt mandates. Bundling T1–T5 before useful decisions is procrastination. Build the smallest real-hook outcome comparison; fix parser corruption and stale descriptions independently.

4. **Strongest arguments**

**Against shedding:** the owner chose superpowers as the backbone; ACS’s sequencing and evidence consumers encode that choice. Zero observed invocation can mean broken routing or an unobserved population, not useless procedure. I would change my mind after matched multi-turn ablations preserve outcomes, artifact handoffs, and legitimate gate passage while reducing cost.

**For shedding:** ACS can duplicate—and fossilize—the backbone’s instructions. Confirmed stale descriptions justify removing contradictory overlays now. I would retain broader mandates only if they prevent concrete failures beyond superpowers alone; skill uptake is insufficient evidence.

5. **One measurement**

Run a paired, randomized-order, multi-turn **routing-block ablation**: identical pinned model, effort, superpowers bootstrap, available skills, context, and gates; only ACS’s per-prompt injected block varies. Use isolated historical tasks with hidden checks, including ambiguous prompts and legitimate pushes; score success, regressions, false blocks, tokens, and time. Keep reference answers inaccessible. I would disable the block if removal saves ≥15% cost with a confidence interval excluding more than a predeclared 5-point success loss and no material safety regression. A reproducible outcome advantage exceeding that margin would justify retention; twenty tasks without sufficient precision would remain inconclusive.
